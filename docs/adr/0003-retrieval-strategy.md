# 3. 检索策略：词面基线 → TF-IDF → 可选 embedding

- 状态：已采纳
- 日期：2026-11-21

## 背景

「语义检索」很容易被理解成 embedding 检索，但真正上embedding 会引入依赖、模型下载或 API 密钥，和核心零依赖的目标冲突。内置资料只有 99 块，词面匹配在很多明确提问上已经够用。

## 决策

按成本递增提供三档，默认最低档：

| 模式 | 实现 | 依赖 | 适用 |
| --- | --- | --- | --- |
| 词面（默认） | bigram 词频重叠 + 标题加权 | 无 | 关键词明确的复习提问 |
| TF-IDF（`--semantic`） | 字符 bigram TF-IDF + 余弦相似度 | 无 | 措辞略有变化 |
| embedding（`--vector`） | sentence-transformers 稠密向量 + 余弦相似度 | 可选 | 同义、跨表述召回 |

向量按「模型名 + 原文」哈希缓存在 `.cache/vectors.json`，不入 git。三种模式都在同一份人工标注集上评测；评测集与指标只是历史样本上的回归检查，不外推为真实成功率。

当前样本结果（9 个问题）：词面 hit@1 0.778 / hit@3 0.889；TF-IDF hit@1 0.556 / hit@3 1.000。TF-IDF 召回更全但排序更散，因此默认仍用词面。

## 影响

- 零依赖用户不被强迫安装模型；在线演示也能完整工作。
- 用户能按问题类型自己切换，并看到每种模式的指标差异。
- 代价：embedding 模式的实际效果依赖所选模型，需要使用者自己验证。
