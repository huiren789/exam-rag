# 4. 可溯源到句子，而不只是资料块

- 状态：已采纳
- 日期：2026-11-21

## 背景

回答已经会列出命中的资料块标签，但一块可能包含多个知识点。用户仍需手动通读整块才能确认答案来自哪一句，「可溯源」体验不完整。

## 决策

在结构化结果中增加 `evidence` 字段：每个命中块返回与问题词面重合度最高的一句原文，附上标签、掌握等级和重合词数。CLI、Web 页和 API 都展示这一信息。重合度只是排序与提示用途，不参与答题生成，不宣称是模型置信度。

## 影响

- 用户能直接跳到依据句，核对成本更低。
- API 响应新增字段，旧客户端忽略即可，不破坏兼容。
- 代价：句子切分按中文标点和固定长度启发式完成，对极长句或跨句表述不完美。
